## jvmguard란 무엇인가요?

jvmguard는 **프로덕션** 환경의 JVM을 모니터링하며 모니터링되는 애플리케이션에 낮은 오버헤드만 추가합니다. jvmguard는 두 가지 가벼운 데이터를 기록합니다. 선택한 메서드 호출의 타이밍인 **트랜잭션**과 힙 사용량이나 스레드 수 같은 스칼라 값인 **텔레메트리**입니다. 이 데이터를 바탕으로 jvmguard는 설정된 조건이 충족되면 JFR 기록, 힙 덤프 또는 스레드 덤프와 같이 대상이 지정된 프로파일링 캡처를 수행할 수 있습니다. 캡처된 스냅샷은 JProfiler 및 다른 프로파일러에서 열어 상세히 분석할 수 있습니다.

캡처는 UI에서 수동으로 시작하거나 REST 또는 MCP API를 통해 시작할 수도 있습니다. 모든 캡처 작업은 감사 로그에 기록됩니다. 액세스는 관리자, 프로파일러, 뷰어의 세 가지 액세스 수준으로 제어되므로 하나의 서버를 여러 팀이 나누어 사용할 수 있습니다.

jvmguard는 애플리케이션과 항상 함께 실행되도록 만들어졌습니다. 따라서 **이력 데이터**를 유지하고 모니터링되는 값이 시간에 따라 어떻게 변화하는지 보여 줄 수 있습니다. 데이터는 오래될수록 자동으로 세분성이 낮아지므로 저장 공간 소모 속도가 느린 상태로 긴 기간을 돌아볼 수 있습니다.

jvmguard는 **여러 VM을 동시에 모니터링**하도록 설계되었습니다. 고정된 VM 설치가 여러 개 있든 수백 개의 VM이 있는 클라우드 배포든 jvmguard는 이를 함께 모니터링하고 구성할 수 있습니다.

jvmguard UI는 여러 사용자가 수집된 데이터를 동시에 분석할 수 있는 **웹 인터페이스**입니다.
