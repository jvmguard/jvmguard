jvmguard는 **서버**와 **에이전트**의 두 가지 주요 부분으로 구성됩니다. 에이전트는 모니터링되는 VM에 로드되어
데이터를 기록합니다. 에이전트는 jvmguard 서버에 연결됩니다. 서버는 연결된 모든 에이전트를 주기적으로 조회하고
그 데이터를 처리합니다. 이력 정보는 데이터베이스에 기록됩니다. 사용자는 웹 브라우저로 jvmguard 서버에 로그인하여
기록된 데이터를 분석합니다.

내부적으로 jvmguard 서버는 세 가지 구성 요소로 이루어져 있습니다:

* 수집기는 모니터링되는 VM의 jvmguard 에이전트로부터 TCP 연결을 수락합니다. 이 연결은 암호화하고
인증할 수 있으므로 광역 네트워크에서도 사용할 수 있습니다. 수집기는 또한 데이터베이스의 데이터를 통합하고,
트리거를 실행하며 그 액션을 수행합니다.
* 내장 H2 데이터베이스는 기록된 데이터와 구성을 포함한 모든 영구 데이터를 "jvmguard"라는 단일 데이터베이스
파일에 저장합니다.
* UI 서버는 사용자가 로그인하여 수집된 데이터를 조회 및 분석하고 서버를 구성할 수 있는 HTTP 또는 HTTPS
연결을 수락합니다.
