jvmguard 구성을 보내고 가져오는 데에는 여러 가지 동기가 있습니다:

* **백업**: jvmguard 서버 구성을 가끔 백업하는 것은 좋은 생각입니다. 구성에는 트랜잭션과 예상 동작에 대한
많은 지식이 포함되어 있습니다. 버전 관리 시스템에 저장할 수 있는 가치 있는 데이터입니다.
* **스테이징**: 프로덕션 서버에 배포하기 전에 jvmguard 구성의 변경 사항을 시험해 보는 스테이징 환경이 있는
경우 한 jvmguard 설치에서 다른 설치로 구성을 전송하는 방법이 필요합니다.
* **무인 배포**: jvmguard 서버를 원격 머신에 배포하는 경우 jvmguard의 무인 설치 모드를 사용하여 jvmguard
서버가 아직 설치되지 않은 서버 인스턴스에 설치할 수 있습니다. 이 경우 별낸 구성을 설치 프로그램 옆에
배치해야 합니다.

## 서버 구성

관리자라면 일반 설정으로 이동하여 "가져오기 / 보내기" 탭을 선택할 수 있습니다. 전체 구성이 JSON 파일로
보내기됩니다. 해당 파일을 가져오면 전체 서버 구성이 대체됩니다. **설정 적용**을 클릭해야 변경이
적용됩니다. 이 방법으로 현재 사용자를 삭제하는 것은 불가능합니다.

<Figure src="ui/config_export_server.png" />

JSON 파일 형식은 버전이 지정되며, 더 최신의 jvmguard 서버는 이전 버전에서 별낸 파일을 읽을 수 있습니다.

해당 파일의 이름을 `jvmguard_server_config.json`으로 지정하고 jvmguard 데이터 디렉터리에 복사하면 시작 시
전체 구성이 덮어씌워집니다. 이 메커니즘은 [무인 설치](/docs/ko/config/unattended-installations)에서
사용됩니다. 가져오기 후 파일은 자동으로 삭제됩니다.

## 기록 설정

전체 구성이 포함된 별낸 JSON 파일에는 사용자 데이터가 포함됩니다. 이것은 스테이징이나 백업 목적으로
원하는 것이 아닐 수 있습니다. 기록 설정에서는 선택한 VM 그룹 구성을 별낼 수도 있습니다. 여기에서 "모든
VM" 또는 특정 VM 그룹을 선택하고 오른쪽의 보내기 버튼을 클릭할 수 있습니다.

이 보내기는 관리자뿐만 아니라 "프로파일러" 액세스 권한이 있는 사용자도 사용할 수 있습니다.

이 파일의 이름을 `jvmguard_recording_config.json`으로 지정하고 jvmguard 데이터 디렉터리에 복사하면 시작 시
전체 기록 설정이 덮어씌워집니다. 가져오기가 완료된 후 파일은 자동으로 삭제됩니다.
