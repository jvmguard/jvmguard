## 什么是 jvmguard？

jvmguard 在**生产环境**中监控 JVM，并且只给受监控的应用程序增加很低的开销。它记录两类轻量数据：所选方法调用的耗时，称为**事务**；以及堆使用量或线程数等标量值，称为**遥测**。基于这些数据，当满足配置的条件时，jvmguard 可以进行有针对性的分析捕获，例如 JFR 记录、堆转储或线程转储。捕获的快照可以在 JProfiler 和其他分析器中打开，以进行详细分析。

也可以从 UI 手动启动捕获，或通过 REST 或 MCP API 启动。每个捕获操作都会记录在审计日志中。访问由三个访问级别控制：管理员、分析员和查看者，因此可以将单个服务器划分给多个团队使用。

jvmguard 旨在与应用程序一起持续运行。这使其能够保留**历史数据**，并展示受监控值随时间的变化。数据会随着时间的推移自动降低粒度，因此可以回溯很长的时间跨度，而存储空间的消耗速度很慢。

jvmguard 旨在同时**监控多个 VM**。无论拥有若干固定的 VM 安装，还是拥有数百个 VM 的云部署，jvmguard 都可以将它们一起监控和组织起来。

jvmguard UI 是一个 **Web 界面**，多个用户可以同时使用它来分析收集到的数据。
